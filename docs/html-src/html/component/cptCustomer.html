소비자중심경영(CCM) 인증 이란?

기업이 수행하는 모든 활동을 소비자 관점에서 소비자 중심으로 구성하고 관련 경영활동을 지속적으로 개선하고 있는지를 심사하여 인증하는 제도입니다.

소비자중심경영(CCM)의 구조를 시각적으로 설명한 다이어그램입니다. 상단에는 '소비자중심(CCM)' 로고와 '공정거래위원회' 문구가 표시되어 있으며, 중앙에는 '소비자의 소리(VOC)'가 핵심 출발점으로 제시되어 있습니다.
